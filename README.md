# Muhammad Ahmad Ashfaq – Portfolio

React + Vite + Tailwind CSS + React Router + Lucide.

    npm install
    npm run dev      # development
    npm run build    # production build in dist/

Supplied files live in `public/` and are used as-is:
`Muhammad_Ahmad_Ashfaq_CV.pdf`, `Muhammad_Ahmad_Ashfaq_CV.png`, `profile.jpg` / `profile.webp` (resized from the original photo).
Host on a static host with SPA fallback (`public/_redirects` for Netlify, `vercel.json` for Vercel).
